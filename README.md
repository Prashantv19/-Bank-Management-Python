# Bank Management System – Python

A simple **Bank Management System** developed in Python. This project is designed to practice core Python programming concepts and basic data handling for a banking application.

## 📌 Project Overview

The project contains Python files and a JSON data file used to build and manage a basic bank management workflow.

### Main Files

- `app.py` – Application-related Python code.
- `main.py` – Main program/entry point.
- `data.json` – Stores application data in JSON format.
- `hello.py` – Basic Python practice/testing file.

## 🛠️ Technologies Used

- **Python**
- **JSON** for data storage

## ✨ Features

The project is intended to demonstrate basic banking-management functionality using Python and JSON-based data handling.

> **Note:** Features may be expanded as the project develops.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <repository-folder>
```

### 2. Run the Python program

```bash
python main.py
```

If the application is started from `app.py`, use:

```bash
python app.py
```
